## Integrantes

- Gustavo Prado de Paula

## Descrição

O projeto implementa um banco de dados relacional para gerenciar clientes, funcionários, filmes, salas, sessões e ingressos de um cinema.

O sistema utiliza chaves primárias, chaves estrangeiras, restrições de integridade, triggers para aplicação de regras de negócio e uma view para consulta consolidada dos ingressos.
